# SKYEBANK - Bank Loan Eligibility Website

A web applicaton that helps the decision-support application that is designed to automate the initial screeening processs for loan applicants. By evaluating multiple criteria from the bank, the website provides a decision wether an applicant is "Eligible" and go to the bank to settle with the application and interview or "Denied" and cannot proceed any further
